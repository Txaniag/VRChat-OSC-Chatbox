一、项目概述
================================================================================

这是一个 Windows 桌面应用程序，用于通过 OSC 协议向 VRChat 聊天框发送文字消息。
支持手动打字输入和语音识别输入两种方式，语音识别完全离线运行，不需要联网。

核心功能：
  1. 文字输入框 -> 通过 OSC 协议发送到 VRChat 聊天框 (/chatbox/input)
  2. 语音识别 -> 使用 SenseVoice 模型离线识别中/英/日/韩/粤语
  3. VAD 语音活动检测 -> 说完话自动截断并识别，可自动发送
  4. 全局热键 -> 在任何界面（包括游戏内）按住/切换按键控制录音
  5. 横屏/竖屏布局切换 -> 竖屏单列，横屏左右双列（左操作右历史）
  6. 设置面板 -> 可调字体大小、VAD参数、最大字符数等
  7. 历史记录 -> 双击可重新填入

二、技术栈
================================================================================

三、硬性约束（必须遵守）
================================================================================

  1. 完全离线：由于在中国大陆使用，不能用 Google 等在线语音识别 API
     -> 必须使用本地模型 (SenseVoice int8, 228MB)
     -> 所有依赖（原生 DLL + 模型文件）必须打包进单个 EXE

  2. 语音识别精度：用户要求高精度
     -> 使用 SenseVoiceSmall int8 模型，支持中/英/日/韩/粤语
     -> VAD 使用 Silero 模型做端点检测

  3. 免手动操作：用户希望说话后自动发送，不需要点按钮
     -> 连续监听模式 + VAD 自动端点检测 + "识别后自动发送"选项

  4. 全局热键：用户需要在 VRChat 游戏内也能触发语音录音
     -> 使用 keyboard 库注册全局热键
     -> 支持按住说话(hold)和按键切换(toggle)两种模式
     -> 注意：游戏内热键可能需要管理员权限运行 EXE

  5. 打包为单一 EXE：用户明确要求 EXE 而非开发模式
     -> 使用 PyInstaller --onefile 模式
     -> 模型文件通过 --add-data 打包进 EXE

六、重要技术注意事项（踩过的坑）
================================================================================

  1. sherpa-onnx API 调用方式：
     - 错误写法: recognizer.get_result(stream)  -> 不存在此方法
     - 正确写法: recognizer.decode_stream(stream); text = stream.result.text
     - 必须先 create_stream() -> accept_waveform() -> decode_stream() -> stream.result.text

  2. VAD (Silero) 使用方式：
     - VadModelConfig 配置参数: threshold, min_silence_duration, min_speech_duration
     - VoiceActivityDetector 的 buffer_size_in_seconds=60
     - 流程: vad.accept_waveform(samples) -> 检测 vad.is_speech_detected()
     - 取出语音段: while not vad.empty(): seg = vad.front; audio = seg.samples; vad.pop()
     - 停止时: vad.flush() 再取出剩余

  3. PyInstaller 打包：
     - 必须 --collect-all sherpa_onnx 和 --collect-all onnxruntime
     - 模型文件通过 --add-data 单独添加
     - onefile 模式下模型解压到 sys._MEIPASS，配置/历史写到 sys.executable 同目录
     - 资源路径用 resource_dir() (打包资源) 和 app_dir() (用户数据) 区分

  4. 全局热键 keyboard 库：
     - keyboard.on_press_key(scan_code, callback) / on_release_key(scan_code, callback)
     - 捕获按键时用 keyboard.hook() 监听所有按键
     - 按键自动重复问题：用 _hotkey_key_down 标志位防抖
     - 修饰键(Shift/Ctrl/Alt)单独按下时忽略，不设为热键
     - ESC 键用于取消热键捕获

  5. 音频参数：
     - 采样率 16000Hz，单声道，16bit (pyaudio.paInt16)
     - FRAMES_PER_BUFFER = 512 (Silero VAD 硬性要求)
     - 识别前将 int16 转 float32: samples.astype(np.float32) / 32768.0

  6. PyQt5 线程安全：
     - VoiceEngine 在后台线程运行，通过 Qt 信号把结果传回主线程
     - QTimer.singleShot(0, callback) 用于从 keyboard 回调线程安全调用 GUI 方法

十、已知问题与未来改进方向
================================================================================

  1. EXE 体积较大 (~296MB)：主要因为 SenseVoice 模型 228MB
     -> 可考虑量化更小的模型，但会降低精度

  2. 全局热键在游戏内可能不生效：
     -> 需要以管理员身份运行 EXE
     -> keyboard 库在部分游戏全屏模式下可能被拦截

  3. 首次打开模型加载较慢 (约2-3秒)：
     -> 模型在第一次录音时才延迟加载，不是启动时加载

  4. 横屏模式下如果窗口太窄，左侧内容可能需要滚动：
     -> 已用 ScrollArea 包裹，可以滚动查看

  5. 图标尚未添加：
     -> 用户已提供图标图片路径，需要在下次打包时加入

  字段                  类型      说明
  --------------------- --------- ----------------------------------------

  min_speech_duration   float     最短语音时长(秒)
  max_chars             int       最大字符数 (默认144)
